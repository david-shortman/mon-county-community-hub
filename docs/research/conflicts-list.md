# Conflicts list: public listings that disagree

Last checked: 2026-10-30

For issue #223. Each item shows what each public source says, quoted as closely as possible, with links and the date we read it. This list does not say which source is right. It is for the owner to send to the people who keep each listing. Where a source page uses a dash in a time range, the quote below writes "to" instead, per our style rules.
