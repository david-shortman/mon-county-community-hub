# No update on the Coopers Rock overlook after its planned reopening

- **Found:** 2026-11-02, while checking park facts for #630 (sprint wave 10, #529).
- **What we found:** WV State Parks said on December 10, 2025 that the Coopers Rock main overlook was closed for bridge replacement, with work to be done in July 2026. No later notice says whether it reopened, and the forest page shows no alert.
- **Evidence:** read 2026-11-02: [State Parks press release](https://wvstateparks.com/press-release/coopers-rock-overlook-closed-for-bridge-replacement/).
- **Why it matters:** Visitors cannot tell if the main overlook is open.
- **Who keeps it:** WV State Parks, Coopers Rock State Forest.
- **Status:** open. Call the forest office, 304-594-1561.
