# State youth summer jobs program has a law but no public page

- **Found:** 2026-11-02, while checking summer jobs for teens for #592 (sprint wave 10, #529).
- **What we found:** House Bill 5480 (2026) created the "West Virginia Youth Summer Employment and Career Readiness Program," effective June 12, 2026, for ages 14 to 20, run by the Division of Workforce Development. We found no WorkForce WV page that describes it or says how to apply.
- **Evidence:** read 2026-11-02: [HB 5480 bill status](https://www.wvlegislature.gov/Bill_Status/bills_history.cfm?input=5480&year=2026&sessiontype=RS&btype=bill), [WV Code 5B-2Q-4](https://code.wvlegislature.gov/5B-2Q-4/).
- **Why it matters:** Teens and parents looking for a summer 2027 job cannot find how to join a program the law created.
- **Who keeps it:** WorkForce West Virginia.
- **Status:** open. Not on our site until an official page says how to apply.
