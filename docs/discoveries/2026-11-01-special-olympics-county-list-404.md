# Special Olympics WV's county program lists do not open

- **Found:** 2026-11-01, while re-checking #577 (verification sweep 4, #529)
- **What we found:** The Special Olympics West Virginia contact page links county director lists for 2023 and 2024. Both links return "not found" (404). The page says there are 26 active county programs but does not say which counties.
- **Evidence:** https://sowv.org/contact-us/ (read 2026-11-01); https://sowv.org/wp-content/uploads/2024/03/County-Directors-List-Web-2024.pdf and https://sowv.org/wp-content/uploads/2023/03/County-Directors-List-2023-Web.pdf, both 404 on 2026-11-01.
- **Why it matters:** Families cannot tell from the web whether Monongalia County has an active program.
- **Who keeps it:** Special Olympics West Virginia.
- **Status:** open
