# Scott's Run Thanksgiving backup number differs from its Christmas number

- **Found:** 2026-11-08, while re-reading `/holidays/` sources.
- **What:** Scott's Run Settlement House's seasonal programs page (https://www.srsh.org/seasonal-programs) says "If you cannot fill out this form please call 3045345098" for the Thanksgiving sign-up. The same page gives "(304)435-5098" for Christmas help. The two differ in the first three digits after the area code (534 and 435), so one may be a typo.
- **Why it matters:** Someone who cannot use the online form may call a number that does not reach Scott's Run.
- **What we did:** The site gives only the online form for Thanksgiving and the 304-435-5098 number for Christmas, as before. Which number is right for Thanksgiving needs a person to ask Scott's Run.
