# Morgantown's noise ordinance page is gone, but city menus still link to it

- **Found:** 2026-11-10, while re-reading `/noise/`'s source for #122.
- **What we found:** `morgantownwv.gov/165/Noise-Ordinance` now shows the city's "page not found" (404) page, and it is no longer in the city's sitemap. The city's "How Do I" and "Departments" menus still link to it. It was the only plain web page with Morgantown's quiet hours, party waiver and fines (City Code, Article 527). The city's official code is on Municode, which refuses automated reads, so we could not compare the rules there.
- **Evidence:** pages read 2026-11-10. Details and links are in #1782. Our last good read was 2026-10-31.
- **Why it matters:** someone who taps "Noise Ordinance" in the city's menu gets an error page. The rules now live only inside the full City Code, which is harder to search on a phone.
- **Who keeps it:** the City of Morgantown.
- **Status:** open (#1782). Related: [gone official pages that still lead search results](2026-11-09-dead-official-pages-in-search.md).
