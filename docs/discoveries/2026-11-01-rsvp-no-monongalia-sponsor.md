# The state's RSVP volunteer page lists no program for Monongalia County

- **Found:** 2026-11-01, while re-checking #559 (verification sweep 4, #529)
- **What we found:** The state AmeriCorps Seniors page for RSVP (a volunteer program for people 55 and older) says "There is no information for this location" for Monongalia County. Marion County shows the same. Preston County lists a sponsor.
- **Evidence:** https://americorpsseniors.wv.gov/RSVP/Pages/counties.aspx?County=Monongalia, read 2026-11-01.
- **Why it matters:** Older adults who want to volunteer through RSVP cannot tell whether there is a local program or whom to ask.
- **Who keeps it:** Volunteer West Virginia, which runs AmeriCorps Seniors in the state.
- **Status:** open
