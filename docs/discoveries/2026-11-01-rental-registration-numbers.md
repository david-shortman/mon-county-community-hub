# The city's rental page gives two numbers for checking a registration

- **Found:** 2026-11-01, re-checking health, family and benefits listings (#529)
- **What we found:** The Occupancy part of the city's Rental Information page says to call 304-284-7401 to check whether a unit is registered. The Registration part of the same page says to call Code Enforcement at 304-284-7528 to verify registration. The page footer shows a third number, 304-284-7405.
- **Evidence:** https://www.morgantownwv.gov/176/Rental-Information, read 2026-11-01. The page moved from /435/ to /176/ without a note; the old address redirects.
- **Why it matters:** Renters checking a place before they sign a lease don't know which line to call. Issue #564 tracks this.
- **Who keeps it:** City of Morgantown Code Enforcement
- **Status:** open
