# City Bicycle Board page is gone and its last agenda is from 2018

- **Found:** 2026-11-02, while checking group rides for #630 (sprint wave 10, #529).
- **What we found:** The city's Bicycle Board page returns "not found," the newest Bicycle Board agenda in the Agenda Center is from September 6, 2018, and the board is not on the Boards or Commissions lists. The Pedestrian Safety Board page still lists a Bicycle Board seat, and the Mon River Trails Conservancy still links to the old page.
- **Evidence:** read 2026-11-02: [Bicycle Board (404)](https://www.morgantownwv.gov/291/Bicycle-Board), [Agenda Center](https://www.morgantownwv.gov/AgendaCenter), [Boards](https://www.morgantownwv.gov/168/Boards).
- **Why it matters:** People looking for city bike rides or the board's meetings find dead ends.
- **Who keeps it:** City of Morgantown.
- **Status:** open. Call City Hall, 304-284-7405, to ask if the board still meets.
