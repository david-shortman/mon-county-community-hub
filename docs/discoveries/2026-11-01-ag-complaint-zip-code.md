# Attorney General complaint page and form give different ZIP codes

- **Found:** 2026-11-01, re-checking the broadband complaint listing (lane B re-check, #529)
- **What we found:** The Attorney General's consumer complaint page gives the mailing address as P.O. Box 1789, Charleston, WV 25326-1789. The printed Broadband Consumer Complaint form (page 4) gives P.O. Box 1789, Charleston, WV 25325.
- **Evidence:** https://ago.wv.gov/consumer-protection/file-complaint-consumer-protection-division and https://broadband.wv.gov/wp-content/uploads/2026/01/WVAG-Broadband-Complaint-Form-Fillable.pdf, both read 2026-11-01.
- **Why it matters:** People mailing a complaint can't tell which ZIP code to use. Our listing uses the web page's address.
- **Who keeps it:** WV Attorney General, Consumer Protection Division
- **Status:** open
