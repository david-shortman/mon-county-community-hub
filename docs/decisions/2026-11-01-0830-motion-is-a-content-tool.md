# Scroll stories and swipe cards are a content tool

- **Date:** 2026-11-01
- **Decided by:** David, in the Claude Duet interactive explainers channel
- **Decision:** Scroll stories and swipe cards are one of the tools agents consider when planning or writing content. `docs/design/motion.md` says when to use them, when a page must stay still, and how to build them. The presentation guide lists both as building blocks.
- **Why:** David said movement is "an option in our tool belt that agents should stay aware of for content". Used with care, it explains processes and changes faster than text alone. The motion guide keeps it off crisis and task pages and keeps every page complete with motion off.
