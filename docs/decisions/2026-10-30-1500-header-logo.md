# The header logo is the icon tile plus the name in Fraunces

- **Date:** 2026-10-30
- **Decided by:** David
- **Decision:** the header shows the site icon as a small rounded tile, then "Everything Morgantown" in Fraunces, soft, cut down to the letters in the name and built into each page. This replaces the plain text name, which still read "Mon County Community Hub" (#421).
- **Why:** David asked for a logo "for maturity", then for "a fast loading title that uses some friendlier font that contributes to the identity". He picked the tile over a one-color line drawing and a name-only version, and Fraunces over Nunito, Bitter and the current heading font. The tile matches the browser tab, home screen and link preview. The name-only font is about 2.5 KB with no extra download. Rules: `docs/design/identity.md`, "The logo".
