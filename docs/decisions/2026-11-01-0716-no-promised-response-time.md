# No promised time to act on a fix or removal request (yet)

- **Date:** 2026-11-01
- **Decided by:** David (#502)
- **Decision:** The site does not promise a set time for acting on a group's fix or removal request. Pages that mention the fix form give no number of days. Taking down or hiding a wrong item still does not wait for David (see "When a PR waits for David" in `docs/COORDINATION.md`). This can be revisited once there is a record of how fast requests are actually handled.
- **Why:** A promised time is a commitment the project cannot yet show it can keep every time. Not promising one is more honest than missing one.
