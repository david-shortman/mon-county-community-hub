# One repo for every site and app, hosted on GitHub Pages with apps on subpaths

- **Date:** 2026-10-28
- **Decided by:** David
- **Decision:** One repo for every site and app, hosted on GitHub Pages with apps on subpaths (`/apps/<name>/`). Deploy-only repos or a monorepo-aware host (Vercel and similar) are fallbacks that keep the code in this repo
- **Why:** Pages costs nothing; one repo keeps data, code, and design shared
