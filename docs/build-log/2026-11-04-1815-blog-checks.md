# 2026-11-04: Blog post checks (#1705)

- **Considered:** the blog's first post (#1709) should not go to the owner until the checks in #1705 are in place. The feeds (#1703) shipped separately in #1725.
- **Chose:** the checks in their own PR for the owner. Their rules and README name 211, 988 and 911, since the rule allows those only as links to help pages, so the High stakes check sends this PR to the owner.
- **Shipped:** `site/scripts/check-blog.mjs` runs in `check-content`, with the rules in `site/src/lib/blog-checks.mjs`. They stop a post that has:
  - a phone number, hours or a time of day, a dollar amount or an income limit (link the page instead)
  - 211, 988 or 911 outside a link to `/help/`, `/stay-tonight/`, `/tonight/`, `/mental-health/` or `/drugs-and-alcohol/`
  - the owner's name, or an em dash
  - "now", "currently", "so far" or "to date" in a sentence with no date
  - a GitHub link asking readers to report a problem (GitHub links as sources are fine)
  - a `pages` entry or site link that is not a page

  A bad fixture post (`site/scripts/fixtures/blog-bad/`) tests each rule on every run, and the sample post must pass. The rules are listed in `content/blog/README.md`.
- **Checked:** `npm run check-content` passes with no posts. Reading grade, time words, contrast, weight and accessibility already scan every built page, so `/blog/` pages get them.
- **Scoreboard:** none. This is a safety check on what posts may say.
