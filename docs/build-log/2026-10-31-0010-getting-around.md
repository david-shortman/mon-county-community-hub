# 2026-10-30: Getting around without a car, and which bus goes to the hospitals (#599, #61)

- **Considered:** the site had no page on riding the bus. Bus times to Ruby Memorial sat in a 2021 PDF, which is hard to read on a phone (findability q28).
- **Chose:** one page, `/getting-around/`, in the Living here door (topic `moving`). It is built only from Mountain Line's own current pages on busride.org, read October 30, 2026. Each fact sits in a resource record, so its source and checked date show on the card.
- **Shipped:** records `mountain-line-fares`, `mountain-line-wvu-ride-free`, `grey-line-pittsburgh`, `mountain-line-newfit`, `bus-to-ruby-memorial` (Route 9 Purple Line, plus late-night Route 1 Campus PM) and `bus-to-mon-general` (Route 47 Northern Circulator from Mountaineer Station). Each route record gives first and last runs from the route's own page and links to it, and the page links the Mountain Line trip planner for live times. Also: a "get around without a car" pick on the Living here door, and an llms.txt line. The existing org `mountain-line-transit-authority` now carries the `moving` topic too.
- **Left off:** PRT hours (WVU pages return 403, see #598). How many Grey Line trips run each day (the WVU Ride Free page says twice, the Grey Line page says 3, see #598). A bus to the DoHS office, Health Right and food pantries: no Mountain Line route page names a stop at them, so the page says so and points to the trip planner.
