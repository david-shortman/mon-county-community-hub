# 2026-11-03: CI upkeep: Node 24 actions, a faster accessibility scan, sturdier wait and merge scripts (#529)

- **Considered:** every Actions run warned that Node 20 actions are deprecated and that `ubuntu-latest` is moving to Ubuntu 26. Pull request Site runs took about 8 to 11 minutes of job time. We also looked for flaky tests in the last two days of runs and at how `scripts/pr-wait.sh` and `scripts/safe-merge.sh` behave when a run is superseded or the head commit moves.
- **Shipped:**
  - #1595: all 11 workflows on the Node 24 majors (checkout v7, setup-node v7, upload-artifact v7, upload-pages-artifact v5, deploy-pages v5), and `runs-on: ubuntu-24.04`, so the move to Ubuntu 26 happens on purpose in its own PR. Site, deploy, High stakes, Claude review and Health all passed on the new versions with no deprecation warnings.
  - #1603: the accessibility scan checks pages in 4 browser tabs at once and prints results in page order. Same checks, same output.
  - #1598: `pr-wait.sh` follows a head that moved (a push from elsewhere, or a merge from `main` made on GitHub) instead of timing out or reporting the old commit's cancelled checks. `safe-merge.sh` hands the merge commit to `pr-wait.sh main` and reads High stakes runs from that workflow's own list. Refusal rules are unchanged. `scripts/test/pr-wait.test.sh` (14 cases, fake `gh`, about 2 seconds) runs in the Site workflow.
- **Run times (build job on pull requests):**

  | | Accessibility scan | Whole job |
  |---|---|---|
  | Before (12 runs, Nov 1 to 3) | 196 to 317 s | 392 to 699 s |
  | After, runner with a slow build (267 s) | 160 s | 512 s (similar runs before: 650 to 680 s) |
  | After, runner with a fast build (165 s) | 103 s | 327 s (similar runs before: 489 to 497 s) |
  | Locally, 4 cores | 447 s to 165 s | |

  The build itself (140 to 286 s, about 0.3 s per page) is now the largest step. Making page rendering faster is a separate job.
- **Flaky tests:** one test failed and then passed on a rerun in the last two days: "pressing Shift three times leaves" in `e2e/crisis.test.mjs` (`ERR_ABORTED`, Nov 1, two runs). It was already fixed by #1241 at 03:31 UTC Nov 1, and no run since has hit it. The other failures were real problems on their branches, fixed before merge.
- **Skipped:** caching Playwright's browser. Pull request caches stay with their own PR and `main` never installs the browser, so nearly every PR would miss. The install is 15 to 20 seconds, mostly system packages.
- **Cost:** $0 (free GitHub Actions minutes; shorter runs use fewer).
