# 2026-10-31: Community numbers page, first slice of the dashboard

- **Considered:** #15 lists Census ACS, BLS, FRED, CDC PLACES, County Health Rankings, HUD and LSC eviction data. Tried each for a free, keyless, machine-readable source. The Census API now redirects every request without a key to a "missing key" page, and a key would need a secret (David's call), so ACS waits. FRED's CSV link returned 404 for the county series. The BLS public API (v1, no key) and CDC's PLACES data on data.cdc.gov (no key) both worked.
- **Chose:** start with those two. The page shows Monongalia County's unemployment rate by month for 24 months (BLS series LAUCN540610000000003, not seasonally adjusted, as the BLS page states) as one line with a table view and a hover label on each month, and eight CDC PLACES 2025-release estimates for adults (2023 data): food insecurity, housing insecurity, utility shut-off threat, lack of reliable transportation, lack of health insurance (ages 18 to 64), routine checkup, frequent mental distress, and smoking, each with CDC's own label and its likely range. The text says the CDC numbers are model-based estimates, not counts, and never calls a number good or bad.
- **Shipped:** `site/src/lib/indicators/` (fetch at build, dated saved copy as fallback, never fails the build), `npm run update-indicators`, and `/how-we-are-doing/` in the Your community door. Checked on a 390px phone screen in light and dark.
