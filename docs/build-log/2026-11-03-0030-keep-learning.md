# 2026-11-03: Keep learning as an adult

- **Considered:** the life areas gaps in #222. Learning had pages for jobs, high school equivalency and English, but nothing for an adult who wants to learn for its own sake. The OLLI record (classes for 50 and older) existed but no page showed it, and the site never named the library's Libby, hoopla, Mango Languages or Learning Express.
- **Chose:** a new page, `/keep-learning/`, built from existing records (library card and programs, ArtistWorks, tutoring, OLLI, BOPARC wellness classes and sign-ups, MTEC evening, adult education and English classes, Literacy Volunteers) plus one new record for the library's e-books and language lessons, read on `mympls.org` on November 2, 2026. One fact record gives the state rule on lower college tuition for West Virginians 60 and older (W. Va. Code 18B-10-7a, which a 2026 bill changed from 65 to 60).
- **Left off:** WVU's own senior student page, WVU Extension classes and the WVU museums. WVU's sites refuse automated reads, so a person needs to check what WVU's current rule says (needs-verification issue linked from the PR).
- **Cost:** $0.
