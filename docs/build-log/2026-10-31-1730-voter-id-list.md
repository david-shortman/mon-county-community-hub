# 2026-10-31: Voter ID card as a short list (#973)

- **Considered:** the "What ID to bring to vote" card on the Vote page packed seven kinds of ID and four exceptions into one long paragraph. That is hard to scan, more so on a phone or with a screen reader, three days before the November 3 election.
- **Chose:** two new optional fields for any resource. `options` is a bulleted list of choices where order does not matter. `notes` is a set of short paragraphs shown after the lists. The voter ID card now shows "Bring one valid, unexpired ID:", the seven IDs as a list, then the 65 and older rule, the no-ID rule, the free voter ID card, and the first-time voter rule each as its own short paragraph.
- **Kept exactly:** every word and both sources. A script rebuilt the old paragraph from the new fields and got the same text, character for character. The checked dates did not change, because no fact was re-read or changed.
- **Also:** the JSON-LD description and the MCP server's resource search now include `options` and `notes` (and the MCP server now returns `steps`), so apps and AI tools still get every ID type.
- **Cost:** $0.
