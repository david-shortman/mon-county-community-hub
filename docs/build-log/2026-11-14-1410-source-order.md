# 2026-11-14: The source order and sources with their own slant (#1092, #1095)

- **Considered:** the rules said to prefer a group's own page, but gave no order of sources and no limit on news, directory or copy sites, and nothing said how to use a source with its own interest (an advocacy group, a business, a campaign).
- **Chose:** a four-tier order (the owner, another office or funder, local news, directories) with a table of which facts each tier may support, and a rule that an interested source is used only for facts about itself. Recording a tier on each of 1,716 sources would be slow and easy to get wrong, so one short list of news and directory sites (`content/source-tiers.yaml`) marks the lower tiers and every other site counts as the owner or an office.
- **Shipped:** `docs/playbook/source-order.md`, `docs/playbook/slanted-sources.md`, TR10 in the trust rubric, the site list, a `check-content` warning when every source of a listing is news or a directory, and `node scripts/check-source-tiers.mjs` to list them. Cost: $0.
- **Scoreboard:** 21 of 847 listings rest only on news or directory sources today (13 calendar entries, 8 secondhand shops). The review is an issue linked from #1092.
