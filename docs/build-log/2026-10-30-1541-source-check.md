# 2026-10-30: Daily source check with a self-building registry

- **Considered:** a hand-kept list of sources (goes stale, and every content PR would edit it), storing page fingerprints in the repo (needs the workflow to write to the repo) or in an artifact (not on the allowed actions list), and extending the Health link check (runs every 4 hours, too often for slow, polite checks).
- **Chose:** a registry built on each run from `content/` and the built pages, with only exceptions in `content/source-rules.yaml`, using the monitored, manual and reference groups from Crescent City Intel (see `docs/playbook/landscape.md`). A separate daily workflow. Fingerprints are stored in the body of one standing `source-check` issue. Fingerprints ignore digits and the order of text, so dates and shuffled lists do not raise false alarms. The phone check reads lettered numbers like 1-800-QUIT-NOW, and it also reads numbers kept in page code (VA pages do this).
- **Shipped:** `site/scripts/check-sources.mjs`, `site/scripts/source-issue.mjs`, `.github/workflows/sources.yml`, `content/source-rules.yaml`, and docs in `docs/operations/README.md`. Closes #16. This covers the "watched sources" part of #122.
- **First run (local, 2026-10-30):** 172 sources checked in about 90 seconds. Nothing broken or moved, and every phone number was found on its source. 6 could not be checked (403 blocks on CDC, FTC, needhelppayingbills.com and WVU Student Engagement, and a refused connection on wvship.org). 9 links redirect to a new address on the same site, worth updating. Two full runs back to back showed no false "changed" alarms.
- **Scoreboard:** no number moves directly. It protects accuracy, the base of findability and action.
