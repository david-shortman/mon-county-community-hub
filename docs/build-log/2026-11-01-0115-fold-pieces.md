# 2026-11-01: Shared pieces for long pages: jump list and fold

- **Considered:** the simulated walkthroughs (#529) found answers 7 to 17 phone screens down long pages. Each page that fixed this would invent its own jump list and collapsing box.
- **Chose:** two small shared pieces, listed in the design guide's building blocks: `OnThisPage.astro` ("On this page" jump list) and `Fold.astro` (a secondary section folded into a native `details`). Styles and one short script live in `Base.astro`: a link to a spot inside a folded section opens it, find-in-page opens it, and print shows it.
- **Rule:** never fold urgent help or a page's main answer.
- **Next:** the long door and guide pages use them, one PR per page (#1174 first).
- **Cost:** $0.
