# 2026-10-31: A manual Actions job for Morgantown 311 totals

- **Considered:** #881, the "how fast" part of #86. David's decision on #300 allows a few big-picture 311 totals credited to SeeClickFix, and no republishing of report data.
- **Chose:** `site/scripts/check-311.mjs` and a `311 totals` workflow that runs only when someone starts it. It looks up the Morgantown, WV place by name (and stops unless there is exactly one), reads the last 12 months of requests in memory, and prints only counts and medians: requests opened, how many are closed, and median days to close, overall and for street maintenance and potholes. The workflow writes them to the run summary and opens or updates one `for:duet` issue. A person checks them and copies them into `content/` with a PR. Nothing goes on the site from this PR.
- **Tested:** one dry run of the script from the build sandbox reached the API (#881 says it should run on a runner, so I stopped there). It found the place `morgantown` and showed that the API returns only open and acknowledged requests by default, so the script now asks for every status.
- **Cost:** $0 (Actions minutes on a public repo, no key, no account).
