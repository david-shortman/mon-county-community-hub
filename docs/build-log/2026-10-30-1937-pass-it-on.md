# 2026-10-30: Pass it on from every listing card

- **Considered:** #157 asks for print, text to myself, and share on every listing, so helpers can hand a listing on in one tap. The site already had a Share button on calendar cards and a "Text these steps" button on door pages, but not on single listings.
- **Chose:** one small new component, `PassItOn.astro`, added as one line at the end of the resource, place and calendar cards, so the card designs (lane 10) stay as they are. "Text this" is a plain `sms:` link with the name, phone, address, hours, link and checked date filled in, so the person's own phone sends it and nothing is stored. "Print this" prints only that card, with its source, checked date and web address. "Share" uses the phone's share sheet, or copies the link.
- **Left out on purpose:** domestic and sexual violence listings get no Pass it on row, since a text or share leaves a trace on the phone. Those pages keep their quick exit.
- **Works without scripts:** the Text link is plain HTML. Print and Share stay hidden without scripts, and the browser's own print still prints the page with each card's web address.
- **Next:** a page-level Pass it on for guide pages with no cards (the utility bills page), which waits for David since it is a money page.
