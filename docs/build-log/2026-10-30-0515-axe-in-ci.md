# 2026-10-30: Accessibility scan on every pull request (#105)

- **Considered:** axe only ran by hand during design reviews, so a new page could ship with a problem that locks someone out.
- **Chose:** run axe-core in the Site workflow on pull requests, with the same rules as the reviews. Free: Playwright and axe-core come from npm, and the step uses no new GitHub actions.
- **Shipped:** `site/scripts/check-a11y.mjs` (`npm run check-a11y`). It serves the built site, opens every page at 390px in light and dark, and fails on serious or critical problems or on sideways scroll at 320px. Moderate and minor problems are printed but do not fail. It runs on pull requests only, so the daily rebuild and deploys never wait on a browser download.
- **Found and fixed:** `/veterans/` jumped from the page title to a smaller heading; it now has an "In a crisis" heading above the crisis line card.
- **Today:** 27 pages, 0 problems, about 20 seconds plus the browser install.
