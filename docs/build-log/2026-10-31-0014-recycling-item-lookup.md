# Recycling page leads with "What do you have?"

**Issue:** #199 (part of #172)

The recycling page now opens with an item lookup: tap targets for eleven common things (batteries, lumber, cardboard, chemicals, clothes, dishes, TVs, glass jars, paint, shredding, tires), then an A to Z list that says where each one goes and links to its sourced details lower on the page. A curbside label shows only where the page has a source for it (the 2019 hauler guide on glass); everything else says where to take it. Clothes, furniture and building materials link to the new sell or donate page.

It works with no script (anchor links and a plain list) and fits on the first phone screen at 320px. The lede is shorter so the lookup starts higher.

`docs/design/presentation.md` adds the Item lookup block and a table of each guide page's job and lead block.
