# 2026-10-31: A daily winter watch on warming shelter sources (#863)

- **Considered:** a new daily workflow that reads shelter sources and writes `content/tonight/warming-shelter.yaml`. Ruled out: shelter status must never be published by a robot, and the Tonight page (#862) waits for David. A new workflow would also mean a second issue system to maintain.
- **Did:** a watch list, `content/watch/shelter.yaml`, inside the daily Source check: two Dominion Post tag pages, a WAJR search page and the city's News Flash, plus Catholic Charities' Grace Shelter page as a by-hand check (it resets robot connections). Every marker was tested on the live pages on 2026-10-31.
- **Built on the pantry watch** (`site/scripts/watch.mjs`), with three small, optional fields any list can use:
  - `season` (here `11-01 to 03-31`, Morgantown dates): outside it the list is skipped and its saved state dropped.
  - `words`: on the first check of a season a page that mentions one opens the issue, and every change shows the lines around each word.
  - `todo` and `plan`: the list's own instructions and doc in its issue, instead of the pantry text.
  Calendar feed `DTSTAMP` lines no longer count as a change, so a feed can be watched later. Self-tests cover each one. The food list behaves as before.
- **Result:** from November 1, a change in any of these sources opens or comments on one "Warming shelter source changed" issue for a person. Nothing on the site changes on its own.
- **Plan:** `docs/plans/2026-10-31-shelter-watch.md`.
- **Cost:** $0. Four more page requests a day in a job that already runs on GitHub's free runner. No Claude calls, accounts or keys.
