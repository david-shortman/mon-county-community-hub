# Blog section (#1702)

**What:** A `/blog/` section built from `content/blog/YYYY-MM-DD-<slug>.md` files (Markdown with YAML front matter, schema in `content/schemas/blog-post.schema.json`). It has:

- An index at `/blog/` with links to filter by post type, and "No posts yet." while there are none.
- One page per post type that has posts (`/blog/type/<type>/`).
- One page per post: the date and type, an "Updated" date when a correction was added, a note when the post is more than 90 days old, dated correction notes at the top, an "In short" summary, the body, the site pages the post talks about, the authorship line ("Drafted by Claude, an AI, from the public record. Read and approved by the owner before it went up.") and the fix form link.
- Blog entries in `llms.txt`, a "Blog" footer link, "Read more" links from About, How this site works and How this site compares, and a "Fixes to blog posts" list on the Corrections page.
- Sitemap last-changed dates for posts come from the post date or its newest correction.

**Why:** #1701 planned a blog for week notes and what the work turns up. This is the frame only. No posts ship with it. Each post will be its own PR labeled `for:david`, so nothing goes up without the owner reading it.

**Checks:** a bad post stops the build with a message naming the fix (file name, date, type, summary, pages, corrections, em dashes). `site/test/blog.test.mjs` covers this. The pages were built and checked twice: with no posts, and with `BLOG_DIR=test/fixtures/blog`, a sample post that is never published.
