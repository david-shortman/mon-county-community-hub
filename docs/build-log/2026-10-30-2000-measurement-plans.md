# 2026-10-30: A measurement plan template and shared counting rules

- **Considered:** the measurement playbook says to write a plan before a change ships, tag outbound links one way, and show small counts as "fewer than 10", but there was no template and no single home for the rules (#40).
- **Chose:** one folder, `docs/measurement-plans/`, holding the rules, the template, and the plans. One file per plan, so parallel sessions never edit the same file. The scoreboard keeps the results; the plans hold the promises.
- **Shipped:** [the README with the shared counting rules](../measurement-plans/README.md) (link tags `utm_source=monhub`, `utm_medium=site|calendar`, `utm_campaign=<slug>`, all lowercase; counts under 10 as "fewer than 10"), [the template](../measurement-plans/TEMPLATE.md) (question, level, main measure, baseline, check date, what counts as helped, answer quality and use, what else changed, exploratory measures, Changes, Result), and a first plan: [do hub answer pages show up in search](../measurement-plans/2026-10-30-answer-pages-in-search.md).
- **Scoreboard:** Level 1 (Findability). The example plan's main measure is questions with a hub page in search: 0 at baseline (2026-10-28). Check 2026-11-15.
