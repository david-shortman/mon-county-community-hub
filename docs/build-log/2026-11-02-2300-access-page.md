# 2026-11-02: Built for any phone and every reader (#1419, #1420)

- **Considered:** the site keeps many access promises (small pages, 7 to 1 contrast, no sideways scroll with big text, no-signal copies, Quick exit) but said so in one vague line on How this site works. There was no accessibility statement.
- **Chose:** one page under About, `/access/`, that lists each promise with "How we know" and today's number where the build has one. Every promise maps to a check in `docs/operations/promise-checks.md` (#1423). The contrast numbers are worked out from the color tokens on every build (`site/src/lib/contrast.mjs`, now shared with `check-contrast.mjs`), so they can't go stale. Page weights come from the check that runs after the build, so they are a dated measurement. The 50 and 150 KB budgets themselves can't be broken, since a page over budget fails the build. The page credits GOV.UK's "Exit a page quickly" pattern for Quick exit.
- **Also (#1420):** How this site works now gives the real numbers in "Checks that run on their own" and says screen readers and voice control are not yet tested on real devices. How we check says saved offline copies expire after 3, 30 and 90 days. About and How this site works link to the new page.
