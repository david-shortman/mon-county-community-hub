# 2026-11-01: Modern craft research for the identity wave

- **Considered:** David says the site reads clear but generic (#396). Phase 1 of the identity wave (#529) researches directions before builders make preview pages. This lane covered current design thinking ("made by people," anti-template) and CSS and font techniques that are safe and cheap on slow phones.
- **Chose:** [`docs/design/research/2026-11-01-modern-craft.md`](../design/research/2026-11-01-modern-craft.md): browser support from `web-features` 3.44.0, measured woff2 sizes for 13 open-licensed fonts, the current palette in OKLCH with three new 7:1-safe tints, and ten twists ranked by impact per byte. Main findings: a real type scale and visible ruled structure cost under 1 KB and do the most; variable fonts should be cut to static instances to fit the 50 KB urgent budget; Fontshare fonts fail our open-license rule.
- **Cost:** $0.
