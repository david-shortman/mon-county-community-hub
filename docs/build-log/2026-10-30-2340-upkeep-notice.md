# 2026-10-30: A site-wide notice if upkeep stops

- **Considered:** if the people and AI helpers stop, the site keeps rebuilding and looks current while its listings slowly go stale. Critics of civic tech warn about exactly that (#497).
- **Chose:** a notice on every page once nobody has re-checked a listing for 30 days. The trigger is data the build already has: the newest `checked` date in `content/` and the newest Corrections entry. The page also checks that date in the browser, so the notice still turns on if the daily rebuild stops too.
- **Shipped:** "This site is not being kept up right now. Nobody has re-checked a listing since <date>..." with a pointer to the groups themselves and to 211. Nothing else on the site changes. The setting and how to turn it off are in `docs/sustainability.md`.
- **Tested:** a normal build (notice present but hidden) and a build with the last re-check set to September 1 (notice shown on every page).
