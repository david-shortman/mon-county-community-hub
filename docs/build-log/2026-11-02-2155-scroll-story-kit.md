# 2026-11-02: Shared scroll story kit and one "Turn off motion" switch (#1441)

- **Considered:** about ten more explainers are planned under #1440. Follow one listing (#1409) and When the buses run (#1426) each carried their own copy of the motion setting, the switch and the step watcher, so turning motion off on one page did not use the same code as the other.
- **Chose:** one small module, `site/src/lib/motion-client.mjs`: `motionAllowed()`, the switch (`bindMotionSwitch`), the step watcher (`watchSteps`) and a swipe card helper (`swipeCards`) for #1442. The switch markup lives in `motion-markup.mjs`, used by `MotionSwitch.astro` and by the bus story's string markup, with one shared stylesheet, `src/styles/motion-switch.css`, on the spacing tokens. No library.
- **Shipped:** both live explainers now use the kit. Same words, same pictures, same behavior with motion on, motion off, reduced motion and no script (checked in Chromium at 390px). Turning motion off on one page keeps it off on the other, as before, through `em-motion-off`. Scroll story and Swipe cards rows added to `docs/design/presentation.md`. Tests: `site/test/motion-client.test.mjs`.
- **Weight:** the kit is 0.78 KB compressed. Because it is now its own file, each of the two pages loads about 0.24 KB more script on a first visit than before; the file is cached, so every later explainer page saves about 0.8 KB.
