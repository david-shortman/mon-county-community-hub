# 2026-10-30: Text follows the reader's text size setting (#100)

- **Considered:** #100 (body text set in pixels, so a person who sets larger text in their browser got no change) and the larger staying well pieces (#244 to #246). This was an extra, off-schedule run late in the day, so I picked something that fits in one sitting.
- **Chose:** #100. The skip link from that issue already existed. The body text was still 18px. Changing it to 1.125rem keeps the same size by default and lets it grow with the reader's setting. Testing at 320px wide with 200% text then showed 12 pages scrolling sideways, because the button grid had a 9.5rem minimum column and long web addresses and phone numbers could not wrap. Fixed those in the shared styles. The bottom tab bar labels keep their current size so the five tabs still fit.
- **Shipped:** `site/src/layouts/Base.astro`: body text in rem; button columns can shrink to the card width; long words and links wrap inside page content; phone numbers inside buttons can wrap at their dashes; tab bar labels capped at their current size. Tested all 17 pages at 320px with 100% and 200% text: no sideways scrolling.
- **Scoreboard:** accessibility rubric A5 (zoom and reflow), scored 2 in the day-one design review. The next design review (#104, by November 11) should score it again.
