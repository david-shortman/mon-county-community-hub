# 2026-11-02: Tests for the access and privacy promises (#1423)

- **Considered:** the promises on Privacy, About, How this site works and `docs/accessibility.md`, one by one, to see which ones a build would catch if a change broke them. Most access promises already had a check (weight, contrast, reflow, 911 and 988). Several privacy promises had none.
- **Chose:** small checks in one new e2e file, `site/e2e/promises.test.mjs`, plus one offline test. Built-HTML checks run in the smoke subset; the browser checks run in the full suite. GoatCounter (#1384) is now the one allowed outside script, named in the test with its reason.
- **Shipped:** checks that fail on an outside font, script, style or image other than the visit counter; any cookie set by our code; any form that asks for a name, email, phone or password or sends data to a server; a Quick exit link without `rel="noreferrer"`; a Text this or Share button on a `private_trace` listing; a saved offline list that is not the same for everyone or does not expire after 3, 30 and 90 days; a page whose first item is not "Skip to main content"; anything moving with reduced motion on (a sample of pages); and the scroll story not working with scripts off or not stopping with Turn off motion. `docs/operations/promise-checks.md` maps every promise to its check, or says why it has none.
- **Scoreboard:** no change in numbers. The access page (#1419) will link the promise map.
