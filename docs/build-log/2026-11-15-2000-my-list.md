# My list: keep, copy, text and print the pages you saved

**Issue:** #2029 (part of the Topics explorer, #2025)

"My list" (`/topics/#my-list`) sits right under the chips on /topics/. It shows the pages saved from Flip through or from the new Save button on each "Picked for you" line, in the order saved.

- **Remove** on each line ("Remove Parks and trails" for screen readers) and **Clear my list**.
- **Copy my list:** the titles and full links as plain text. If the clipboard is not allowed, the text shows in a box, selected and ready to copy.
- **Text it to myself:** an `sms:?&body=` link with the titles and links filled in, so the person's own phone sends it, the same way Pass it on does.
- **Print:** prints just the list.
- **On this phone only:** `localStorage` `em-explore-saved`. Nothing is sent anywhere. With no script, My list does not show. When it is empty, one line says how to add pages.
- **Quiet pages:** pages Pass it on hides (domestic and sexual violence help, `isQuietPage()`) get no Save button and are dropped from the saved, copied and texted list even if they get into storage.
- Flip through's last card now has **See My list**, which closes the deck and moves focus to the list.

The list text is built by `listText()` in `site/src/lib/explore-rank.mjs`, with unit tests. The e2e test saves 3 pages, checks the text link has 3 full links and Copy gives the same text, removes one, reloads, clears, checks the copy box when the clipboard is blocked, checks deck saves, and checks My list is gone with scripts off.
