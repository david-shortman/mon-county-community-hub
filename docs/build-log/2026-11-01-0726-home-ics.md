# 2026-11-01: Home and yearly dates calendar (home.ics)

- **Considered:** #1051. David wants to test a "Home and adulting" calendar on his phone before we build other topic feeds. The calendar had one yearly home date (the homestead deadline) and no way to repeat a date every year.
- **Chose:** a small rules file, `content/home-year.yaml`, with 13 yearly dates: both property tax halves (W. Va. Code 11A-1-3), personal property returns opening and closing, homestead applications opening and closing, the farm status deadline (Monongalia County Assessor pages), the two forest fire seasons (W. Va. Code 20-3-5), and four tips: well water testing (EPA), last spring and first fall frost (NOAA 1991 to 2020 normals for the Morgantown airport, with Red Cross advice on hoses and outdoor faucets) and septic checks (EPA). `site/src/lib/home-year.mjs` turns each rule into its next date in the coming 12 months, so they show on the Dates page and in `calendar.ics` too. `home.ics` adds the live recycling and tire days and the LIEAP window from the calendar as it is. A new page, `/home-calendar/`, lists the dates and gives iPhone and Google steps from Apple's and Google's help pages.
- **Changed from the issue:** frost dates come from NOAA's own data for Hart Field (last spring frost April 23 in half of years, first fall frost October 24) instead of the Almanac page, since NOAA is the public source. CDC's well page and ready.gov refuse automated reads, so the well tip uses EPA and the hose tip uses the Red Cross. The issue's "check the well for mechanical problems" line is left off: the EPA page we read does not say it.
- **No duplicates:** a hand-written file with the same slug wins, so the 2026 homestead deadline and the 2027 second-half tax date still come from their existing files. When those pass, the yearly rule takes over.
- **Staying current:** a rule whose sources were last checked more than 13 months ago drops out of every feed and prints a warning in the build and in `npm run check-content`.
- **Not done:** the subscribe block is not on the Dates page, because that page names 211 and an edit there waits for David. The City of Morgantown Christmas tree pickup is not on the calendar, so it is not in the feed.
