# 2026-11-01: Each page's oldest checked date in its structured data (#122)

- **Considered:** #122 and ADR 0007 asked pages to expose their oldest fact's date in structured data, so search engines and AI tools can see how fresh a page is. A page is only as fresh as its stalest fact.
- **Chose:** schema.org `WebPage.lastReviewed` ("the date on which the content on this web page was last reviewed for accuracy"), not `dateModified`, which would claim the page changed. It is read from the "Checked <date>" lines the page already shows, the same way the sitemap's `lastmod` is (#1044), so it can never disagree with what residents see. Cost: $0.
- **Shipped:** `webPageNode()` and `oldestCheckedShown()` in `site/src/lib/site-meta.mjs`; the build's JSON-LD step adds the node (`site/src/lib/jsonld.mjs`, `site/src/middleware.js`); `check-jsonld.mjs` fails a page whose `lastReviewed` is not its oldest shown date. Widget pages under `/embed/` are left out, because they carry no scripts. Tests: `site/test/last-reviewed.test.mjs`. ADR 0007 updated.
- **Result:** 402 pages now have `lastReviewed`. Pages with JSON-LD went from 378 to 445; nothing else in the data changed.
