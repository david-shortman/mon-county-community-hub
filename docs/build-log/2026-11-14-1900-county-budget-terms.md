# Plain meanings for county budget words (#1880)

Added a "What some budget words mean" box to `/county-budget/`. It gives a one-line plain meaning for four words the PDF uses (Levy Estimate, General Fund, Estimated Revenues, Coal Severance Tax Fund), each followed by the exact words of the West Virginia Code section it comes from, linked and dated (read 2026-11-14 on code.wvlegislature.gov).

Left off on purpose: "Fund Balance" and the 10% contingency limit. No official page we could reach defines them. The box says so and points to the County Clerk. Logged as a discovery; a person follows up in #1891.
