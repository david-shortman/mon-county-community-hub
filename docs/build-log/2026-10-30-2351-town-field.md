# 2026-10-30: Dates and places can name their town

- **Considered:** David picked town names on place cards and a town filter on Dates as quiet local touches (#395). No record had a town field, and the place was only inside the address or the text.
- **Chose:** optional `town` and `neighborhood` fields on calendar entries and resources. `town` must be a name from `TOWNS` in `site/src/lib/towns.mjs`, so the same place is always spelled the same way. Event cards show the town under the title with a small pin, as plain text.
- **Never from a mailing address.** Many places with a "Morgantown, WV" address are outside the city, so the town is set by hand only when the record names the place. Filled 11 dates: Arnettsville, Cheat Lake, Smithtown and Westover events, each matching the community in the gathering places record, plus Masontown and Fairmont events whose own text names the town.
- **Next:** the town filter on Dates (one anchor per town, no script needed) and the town line on place cards.
