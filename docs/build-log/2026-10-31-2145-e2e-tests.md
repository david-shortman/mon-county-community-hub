# 2026-10-31: End-to-end tests, a link check and phone screenshots on every PR

- **Considered:** the site grew to about 240 built pages today, many from parallel sessions. The build checks read files one by one; nothing opened the site in a browser to try what residents do: call 911, 988 or 211, leave with Quick exit, answer the door questions with scripts off, build a what to bring list, add an event to a calendar, or read Tonight on a phone.
- **Chose:** a Playwright suite in `site/e2e/` (39 tests, about 20 seconds), a check of every internal link and `#anchor`, and phone screenshots of 15 key pages saved as a CI artifact on each PR. The full suite runs on PRs that change the site or its content; others get a quick smoke subset. How to run and extend it: [`docs/operations/e2e-tests.md`](../operations/e2e-tests.md). Part of #529.
- **Found:** on its first run, the link check found that the crisis strip's "What is this?" link went nowhere on `/tonight/`, `/mental-health/` and `/drugs-and-alcohol/`. Fixed in #1126 (waits for David, since it touches crisis pages). It also found the 404 page's canonical link points to a page that does not exist, which #938 already fixes.
- **Cost:** $0. Playwright was already a dev dependency. Actions is free on a public repo. The only new action is GitHub's own `actions/upload-artifact`.
