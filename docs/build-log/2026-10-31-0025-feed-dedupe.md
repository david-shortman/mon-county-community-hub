# 2026-10-31: One event, two feeds: show it once

- **Considered:** #852, from the review of #843: the duplicate guard in `loadCalendarWithFeeds` compared feed items only with hand-checked entries, so an event listed by two feeds (say the Farmers Market and Mylan Park) would show twice. Checked today's feeds: no cross-feed duplicates yet. The example in the issue ("Morgantown Winter Farmers Market @ Mylan Park" on November 21 and "Winter Blues Farmer's Market" on December 12) is two different titles on two different dates, so it is not merged.
- **Chose:** the same rule the hand-checked guard uses (same first three title words), plus the same start date, across different feeds. The feed listed first in `ADAPTERS` wins, so the result never depends on which fetch finished first. Two items from the same feed are never merged, since a feed can list two real events with similar names on one day.
- **Shipped:** a few lines in `site/src/lib/content.mjs`. The calendar, `calendar.ics` and the API all read from it.
- **Cost:** $0.
