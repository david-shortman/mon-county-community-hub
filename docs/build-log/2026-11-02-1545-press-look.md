# 2026-11-02: The Press look goes live for everyone (#396)

- **Considered:** keeping Press as a preview stylesheet that every page loads, or folding it into the site. Folding it in means one set of tokens that `check-contrast` and the embed test read, and no extra file to fetch.
- **Chose:** Press tokens are now the site tokens in `Base.astro`. The look's rules live in `site/src/styles/press.css`, inlined after the base styles. Newsreader moved to `site/public/fonts/` and loads only where headings use it. Urgent pages are listed once in `site/src/lib/urgent-pages.mjs`, which both the layout and `check-weight` read. The Log Cabin block is now styled on the 404 page itself, so other pages don't carry it.
- **Removed:** `site/public/looks/` (all three previews), the `/design-lab/` page and the `?look=` switch. A one-line script clears an old preview choice from browsers that still hold one; it can go after December 2026.
- **Also:** the embed frame's colors, the browser bar color and the app manifest now match the new inks.
- **Checked:** all 945 pages within the weight budget, contrast passes (new pairs for sandstone, Cheat water and rust added), `check-pages` passes, 95 of 95 tests pass. No overflow at 320px with 200% text on ten pages. axe (A, AA and AAA rules) clean at 390px and 1280px, light and dark. Crisis pages load no serif.
