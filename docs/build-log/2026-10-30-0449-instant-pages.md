# 2026-10-30: Instant page loads (#151)

- **Considered:** on a slow phone connection, every tap is a wait. Chrome and Android can start loading a page as soon as someone starts to tap or hovers its link, and browsers can fade between pages instead of flashing white.
- **Chose:** two small additions that browsers without support simply ignore. No script, no outside service. Cost: $0.
- **Shipped** in `site/src/components/AppShell.astro`:
  - Speculation rules that prerender only our own pages, with moderate eagerness. Search, Pagefind, the calendar file, XML and text files, and nofollow or download links are left out. Chrome already skips this with Data Saver or low battery on, so it does not spend data people asked to save.
  - `@view-transition { navigation: auto; }` with a 150 ms fade, and none under `prefers-reduced-motion`.
- **Tested** in Chromium with Playwright: the rules parse with no errors, Chrome starts a prerender when the Help now tab is hovered, and the reduced motion rule is in place. Playwright drives Chrome through DevTools, which turns prerendering off, so the last step (opening the prerendered page) still needs a check on a real phone.
- **Scoreboard:** none directly.
