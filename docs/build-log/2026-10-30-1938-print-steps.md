# 2026-10-30: Route steps print with scripts off

- **Considered:** a Trailhead route (`Route` and `Milepost`) opened every step before printing only when scripts ran (#368). With scripts off, a printed utility bill guide left out the closed steps, like the help programs in step 2.
- **Chose:** two lines of print CSS. `::details-content` shows the inside of a closed `details` when printing, and the open or closed arrow is hidden on paper. Supported in Chrome and Edge 131+, Safari 18.4+ and Firefox 143+. Older browsers still get the existing `beforeprint` script, so nothing is lost there.
- **Checked:** Playwright print mode on `/utility-bills/`, scripts on and off: all four steps visible in print, only step 1 open on screen. A PDF printed with scripts off has the LIEAP step text.
- **Cost:** $0.
