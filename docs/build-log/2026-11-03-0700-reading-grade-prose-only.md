# 2026-11-03: Reading grade counts only prose (#1621)

- **Considered:** while rewriting high-stakes pages (#1620, #1627, #1631), the whole-page reading grade stayed high on pages whose writing was plain. The cause was a bug, not the cards themselves: the paragraph pattern in `site/scripts/check-reading.mjs` (`<p[^>]*>`) also matched SVG `<path>` tags in button icons, so each button row ("Call ..., Directions, Add to calendar, Share") was graded as one long sentence.
- **Shipped:** the script now reads only real `<p>` tags, skips source and check lines (`meta`), date chips and the Pass it on address, leaves out screen-reader-only text, and ends a sentence at the end of each paragraph. Tests in `site/test/reading.test.mjs`. Embed listings (one resource card each) are now graded too, but counted on their own as `cards_above_9`, not with pages. The scorecard notes the method change on the full-text row and adds the card count.
- **Measured** (same build, old method to new): whole-page middle grade 7.7 to 5.4; pages above grade 10, 35 to 1. Page openings did not change (middle value 3, 10 above grade 9). New: 179 of 375 resource card "Who it's for" lines are above grade 9.
- **Left:** the sentence counter still misses a period inside a closing quote (`."`), so quote-heavy pages read a little harder than they are. It is left as is because the source benchmark uses the same formula to compare us with other sources.
