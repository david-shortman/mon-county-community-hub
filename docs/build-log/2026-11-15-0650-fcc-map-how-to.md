# Which companies and speeds reach your address: the FCC map how-to

- **Issue:** #2010 (sprint wave 21, #529), from the "remote worker moving here" persona (p20).
- **What changed:** `/internet-service-map/` now starts with how to use the FCC National Broadband Map: search an address, read the green, red and gray dots and the list of companies, speeds and service types, and what the list does not tell you (prices, real speeds). A new section explains the FCC's availability and location challenges and what happens after one. Each sentence is a fact record in `content/facts/internet/fcc-*.yaml`, quoting the FCC's own help center.
- **Why not show the answer for an address:** `broadbandmap.fcc.gov`, `www.fcc.gov` and `docs.fcc.gov` answer robots.txt with a 403, so under `docs/operations/automated-reads.md` no robot reads them. The FCC help center (`help.bdc.fcc.gov`) allows reads, so the steps come from there. The page links to the map; it does not read or embed it.
- **Upkeep:** the map is on the person sources checklist (quarterly), and `content/source-rules.yaml` lists it as manual. The map's data as-of date is not on the site; a `needs-verification` issue holds it. Discovery: `docs/discoveries/2026-11-15-fcc-map-blocks-robots.md`.
- **Left alone:** `/internet/`, which the open PR #1867 changes. It does not link to this page yet; a link from `/internet/#maps` waits for #1867 to merge (noted on #2010). This page is listed in the Living here door.
