# 2026-11-01: A page for every group we list

- **Considered:** a group that finds the site has no single place to see everything we say about it. Its listings are spread over many guides, and the For groups page explains how to ask for a fix but not what we list.
- **Chose:** `/groups/<slug>/` for every group in `content/orgs`, with an A to Z list at `/groups/`. Each page shows the group's record and sources, its listings as residents see them, the printable sheets they are on, its upcoming dates, its JSON records, and how to ask for a fix. Printable with the browser's Print button.
- **No contact:** nothing is sent to any group. The pages are there for a group to find.
- **Found:** two groups have two records each with the same name (Internal Revenue Service, Mountain Line Transit Authority). Both pages build, with the slug in the title, and an issue asks for the records to be merged.
- **Upkeep:** [`docs/operations/group-pages.md`](../operations/group-pages.md).
- **Cost:** $0.
