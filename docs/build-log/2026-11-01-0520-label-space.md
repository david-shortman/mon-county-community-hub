# Space after bold labels on cards

From #1072. On 126 built pages, a bold label ran into its value, like "**Cost:**Free." Astro drops the space in `<strong>Cost:</strong> {value}` when that line sits inside a `{...}` expression. The fix writes `{' '}` after the label in 29 components and pages.

A new check, `site/scripts/check-label-space.mjs`, runs after every build and fails if any page has a bold label ending in ":" or "." right before a letter or digit. On `main` before this fix it would have flagged all 126 pages.
