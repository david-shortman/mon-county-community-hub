# 2026-10-31: Meeting tracker, first piece: Morgantown AgendaCenter

- **Considered:** #12 asks to pull agendas and minutes from the city's AgendaCenter into structured data. The RSS feeds give only the date an agenda was posted, not the meeting date (found in #31). The AgendaCenter page itself lists every board with each meeting's date (in the row label and the file id, like `_10272026-3920`), the agenda link, and the minutes link once minutes are posted. The page is not blocked by the city's robots.txt.
- **Chose:** read the AgendaCenter page at every build, the same way as the calendar feeds: a saved copy in `site/src/lib/meetings/snapshots/` is used if the page is down, and the build never fails because of it. Each record keeps the board, meeting date, agenda title and link, minutes link, source and checked date, plus `first_seen` and `last_changed`, carried over from the saved copy. `npm run update-meetings` refreshes the saved copy and prints new meetings and newly posted minutes, so changes show between runs. Meetings from the last 120 days and ahead are kept. We link to the city's files and never summarize them.
- **Shipped:** `site/src/lib/meetings/` (reader and loader), `site/scripts/update-meetings.mjs`, the `/meetings/` page (agendas posted for coming meetings; recent meetings by board with agenda and minutes links), and a `meetings` type in the open data API (`/api/v1/meetings.json`, added to the v1 contract). 114 meetings from 40 boards in the first copy, 16 with minutes.
- **Next:** County Commission, school board and small towns are #13. A new source is one more entry in `SOURCES` in `site/src/lib/meetings/index.mjs` with its own reader.
- **Cost:** $0.
