# 2026-10-31: Embeds: dates, listing cards and a help now box

- **Considered:** how a library, office or local group could show our dates on its own website without a build step or a developer. The site already had a calendar feed (`calendar.ics`) and JSON files, but both need an app or code to show anything.
- **Chose:** a small "upcoming dates" page made to sit in an iframe, for all of Mon County, one topic, or one town, plus a gallery page at `/embed/` with copy-paste code. Plain HTML, no scripts, no cookies, no tracking. Each date shows its source and checked date and links back. Rebuilt every morning with the site.
- **Also:** a card for every listing (`/embed/listing/<slug>/`), and a help now box with 911, 988 and 211 (`/embed/help-now/`). Every widget footer has the site's 911 and 988 line, so this waits for David.
- **Left off:** town widgets only list dates whose record names the town, the same rule as the Dates page.
- **Upkeep:** [`docs/operations/embeds.md`](../operations/embeds.md).
- **Cost:** $0.
