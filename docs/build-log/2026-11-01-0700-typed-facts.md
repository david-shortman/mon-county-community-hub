# Typed facts on high-stakes pages: a warning

From #1064, after the October 31 high-stakes page audit. On `/utility-bills/`, last season's LIEAP dates stayed on the page after the record was updated, because that line was typed into the page file. Records get checked dates and stale warnings; typed text gets neither.

`site/scripts/check-typed-facts.mjs` now runs in `npm run check-content`. It lists every phone number, dollar amount and date typed straight into a high-stakes page file (the same rules as the High stakes check), with its line. It only warns. 911, 988, 211, 898-211, 7-1-1 and 838255 are allowed.

First run, November 1, 2026: 167 typed facts in 34 files. Many are fine (a "checked" date in a source line, a phone that has no record yet). The list is a place to start moving facts into records, page by page. Street addresses are not checked yet.
