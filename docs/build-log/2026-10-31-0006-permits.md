# 2026-10-31: Do I need a building permit? (#661)

- **Considered:** homeowners ask "is it the city or the county?" before they can find the right permit office (#271). About seven in ten residents live outside Morgantown city limits, where there is no local building code office but other permits still apply.
- **Chose:** one page, `/permits/`, in five steps: check city limits on the Morgantown Zoning Viewer; Morgantown (online portal only, one application per kind of work, Code Enforcement); Star City, Westover, Granville and Blacksville, each with its own office; outside town limits (West Run land use permits with the county's own lists of what does and does not need one, floodplain, state road driveways, State Fire Marshal for commercial and multi-family, septic and wells); and the Assessor's Form 12:75. Every fact is from an official page read October 31, 2026.
- **Left off:** the contractor license dollar limit, which the county page gives but the Contractor Licensing Board has not confirmed (#603), and assessment appeals (#660).
