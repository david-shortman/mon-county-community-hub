# Resident groups

Research for epic #261: who you are, crossed with what you're trying to do. One file per group, named for the group.

Each file lists:

- What people in the group are trying to do, in their words.
- Which pages on our site already help.
- Local programs and offices we confirmed on their own current pages, with the link and the date we checked.
- What we could not confirm. Those facts stay off the site and get a `needs-verification` issue.
- Gaps, each with the build issue opened for it.
- A plan for a short "I'm a ..." starting page that links to existing pages and adds no facts of its own.

These files are research notes, not resident-facing pages. Facts go on the site only through `content/` records or pages that cite their source, after the source is re-read.
