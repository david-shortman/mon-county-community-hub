# Visibility audit: 2026-10-28 (baseline)

The first weekly visibility run. It checks whether search engines and AI answer tools can find, read, and correctly describe the site, and whether residents can find and share it. Method: the weekly visibility prompt, with the rules in [README.md](README.md). Live site checked: https://david-shortman.github.io/mon-county-community-hub/ (no custom domain yet).

## Summary

- **Biggest gap: the site is not in search results yet.** None of the 10 resident searches below showed a hub page, and an exact search for "Mon County Community Hub" found only Monmouthshire (Wales) and Mono County (California). The site is a few days old and no sitemap has been submitted, because that needs search engine accounts (#89).
- **Fixed in this run:** the home page's canonical link pointed to a URL that redirects (301), and `llms.txt` was missing the two newest guides. The page check now catches both.
- **Filed:** #143 (put the place name in guide titles).

Our stay-tonight page answers that directly, so it is a strong citation candidate once it is indexed.
