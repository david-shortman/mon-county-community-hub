# Architecture decision records

Each file records one choice that shapes the system: the context, the decision, what follows from it, and its status.

- One numbered file per decision: `NNNN-<short-name>.md`. Take the next free number.
- Status is one of: proposed, accepted, replaced by NNNN, dropped.
- Never rewrite an accepted record. Write a new one that replaces it.
- The list of records is this folder. There is no index to keep up to date, so two sessions adding records at the same time do not conflict.

A record that changes `CLAUDE.md`, `docs/COORDINATION.md`, the charter, or repo settings needs David before it can be accepted.
